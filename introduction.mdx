## Overview

Martin Acero provides a centralized space to organize and manage all your project documentation. You create, edit, and collaborate on docs using an intuitive interface powered by MDX. Customize your space with themes, integrate APIs, and ensure consistent branding across all content.

<Callout kind="tip">
  Start by inviting team members to collaborate on your first documentation project.
</Callout>

## Quick Start

Get up and running in minutes.

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up at `https://app.martin-acero.com` with your email.
  </Step>
  <Step title="New Space" icon="plus">
    Click "New Space" and name it for your project, like "API Docs".
  </Step>
  <Step title="Add Document" icon="file-plus">
    Create your first `{introduction.mdx}` file with the frontmatter shown below.
  </Step>
  <Step title="Publish" icon="globe">
    Preview and publish to share with your team.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Example API call to fetch docs
  const response = await fetch('https://api.example.com/docs', {
    headers: { Authorization: `Bearer ${YOUR_API_KEY}` }
  });
  const docs = await response.json();
  console.log(docs);
  ```
  ```python
  import requests
  response = requests.get(
      'https://api.example.com/docs',
      headers={'Authorization': f'Bearer {YOUR_API_KEY}'}
  )
  docs = response.json()
  print(docs)
  ```
</CodeGroup>

## Brand Guidelines

Maintain consistency with your brand color `#3B82F6`.

<Expandable title="Color Usage" default-open="true">
  Use the primary blue (`#3B82F6`) for buttons and links. Pair with neutrals for text.

  ```css
  :root {
    --brand-primary: #3B82F6;
    --brand-text: #1F2937;
  }

  .button {
    background-color: var(--brand-primary);
    color: white;
  }
  ```
</Expandable>

<Callout kind="info">
  Customize themes in your space settings to apply `#3B82F6` site-wide.
</Callout>
