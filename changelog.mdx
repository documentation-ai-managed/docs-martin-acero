## Recent Updates

Stay informed about the latest enhancements, bug fixes, and breaking changes in Martin Acero. You receive automatic notifications for major releases through your dashboard at `https://dashboard.example.com`.

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Added real-time collaboration for shared documentation spaces, allowing multiple users to edit simultaneously.
- Introduced version history with diff views, so you can compare changes across revisions easily.

## Improvements

- Enhanced search functionality with fuzzy matching and full-text indexing for faster results.

## Bug Fixes

- Fixed authentication issues when using OAuth providers, resolving token refresh errors.
- Corrected rendering glitches in Mermaid diagrams containing complex node labels.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "improvement"]}>

- Added export options for PDF and Markdown, preserving all formatting and components.

- Improved mobile responsiveness for all documentation pages.

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Initial Release

- Core documentation management with MDX support, including all standard components like `<Callout>` and `<Steps>`.
- Full-text search and tagging system for organizing project spaces.

- Migrated from v0.x config format; update your `martinacero.config.js` files.

</Update>

## Upgrade Instructions

Follow these steps to upgrade Martin Acero to the latest version. Always back up your documentation spaces first.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Export your spaces via the dashboard:

````bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.example.com/v1/spaces/export \
  -o backup.zip
````

  </Step>
  <Step title="Update Package" icon="package">

    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install martinacero@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn add martinacero@latest
````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Restart Server" icon="refresh-cw">

    Run `npm run dev` or restart your production server.

  </Step>
</Steps>

<Callout kind="tip">
  Check the [migration guide](/configuration#upgrading) for v1.2.0 specifics if you encounter config issues.
</Callout>
