## Overview

martin acero helps you keep project docs tidy. Use folders and tags for better organization.

## Best Practices

- Create folders for each major project.
- Use descriptive titles for your documents.
- Add tags for quick searching.
- Archive outdated docs regularly.

## Quick Example

1. Click "New Folder" in the sidebar.
2. Name it after your project (e.g., `Website Redesign`).
3. Drag documents into the folder.
4. Add tags like `design`, `meeting-notes`.
